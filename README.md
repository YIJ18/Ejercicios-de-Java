# Ejercicios-de-Java ☕💻

**Ejercicios-de-Java** is a collection of Java projects and exercises aimed at practicing core Java concepts and GUI development. The repository includes programs built with **Java Swing**, console-based exercises, login forms, and simple games.

---

## 📌 Overview
This repository contains multiple Java exercises designed to reinforce:
- Object-oriented programming (OOP) principles  
- Event-driven programming with Swing  
- GUI design and interaction handling  
- Basic game logic implementation  
- User input and form validation  

Projects include:  
- `LoginForm.java` / `iniciosecion.java` – login form implementations  
- `ComponentesSwing.java` / `PanelOpciones.java` – GUI components and panels  
- `GatoSwing.java` / `Juego1.java` – simple interactive games  
- `Main.java` – entry point for testing exercises  
- `Mensaje.java` – console-based Java exercises  

---

## ✨ Features
- Java Swing GUI applications with interactive components  
- Forms with input validation and user interaction  
- Basic games for learning event handling and logic  
- Well-structured Java projects ready for compilation in IDEs like NetBeans or IntelliJ  

---

## 🛠 Requirements
- Java JDK 8 or higher  
- IDE (NetBeans, IntelliJ, or Eclipse recommended)  
- Basic knowledge of Java and OOP  

---

## ⚙️ Setup
1. Clone the repository:  
   ```bash
   git clone https://github.com/YIJ18/Ejercicios-de-Java.git
   cd Ejercicios-de-Java
   ```
2. Open the `NetBeansProjects` folder or individual `.java` files in your IDE.  
3. Compile and run the desired project or exercise.  

---

## 🚀 Usage
- Explore the projects to understand Java Swing components and event-driven programming.  
- Run the simple games and login forms to test interactive functionality.  
- Modify exercises to practice Java concepts further.
